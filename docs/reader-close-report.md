# 逐行阅读关闭操作修正

原来的顶部“逐行阅读”按钮可以重复点击收起,但打开后名称不变,阅读面板内也没有独立关闭按钮。现在展开后改为“收起逐行阅读”,面板标题旁增加“关闭阅读 ×”,焦点在本段代码或阅读器内时支持 Esc。关闭按钮和 Esc 会把焦点送回顶部入口,并清除当前行高亮、行按钮属性和键盘事件。离页清理复用同一关闭逻辑。

浏览器验证了截图中的 Frida Shell 示例：关闭按钮、顶部收起、Esc(阅读控件/源码行)、重复打开与下一行、多阅读器独立关闭、保留运行区以及离页清理。320、390、768、1440px 下关闭按钮和阅读区均未横向越出视口,且都能正常关闭。
