## 逆向篇的深度

原有 15 章补充了对应主题的证据推导、假设验证、实验前提、失败排查和结论限制，避免只列工具与命令。新增三套可复现的本地实验：

1. **JDK 字节码实验**：自写 Java 样本，预测输出，用 javap 核对描述符、操作数栈与分支；讲解 jdb 断点、参数与调用栈，比较带/不带调试信息的产物。
2. **文件头检查器**：使用 Python 标准库检查 class/PE 文件头，自制不可执行的 PE 夹具；处理截断、越界与未知格式，提供四项单元测试。
3. **离线协议解码器**：长度前缀协议，逐段输入字节流，区分拆分与合并、字节数与字符数；包含中文、空消息、超长帧和非法 UTF-8 等五项测试。

实验围绕自己的程序与无害数据开展。复杂平台工具部分仍依赖各自环境；本次没有逐项安装并执行所有第三方逆向工具，也没有把它们的版本差异全部穷尽。
