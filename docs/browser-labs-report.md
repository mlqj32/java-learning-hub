# 浏览器模拟与代码观察验收

2026-11-15。入口：[模拟实验总览](http://127.0.0.1:8766/#/simulations)。静态网页即可使用这些模型，无需安装 CE、IDA、Frida、Android SDK 或目标软件；Java/Python/SQL 的真实代码运行也已迁移到网站内置的浏览器虚拟环境，详见运行能力报告。

## 本次调整

- 重建冒泡、选择、插入、快速排序。每一步保存独立状态快照，支持单步、回退、播放、暂停、拖动、改输入和切算法；同步显示伪代码、变量、比较/交换/写入次数、元素原始身份。
- 插入排序真实执行暂存 key、右移、回填，移动不再冒充交换；快速排序统一使用 Lomuto 分区。逆序对改为统计所有满足条件的下标对。
- 字节码显示局部变量槽、可视操作数栈、逐条指令和返回值；遵循 Java int 溢出规则。
- 原拼接演示中的固定“实测毫秒”改为按输入计算的复制/写入工作量，不再声称测量了 JVM 性能。
- 28 个演示全部增加操作提示、观察重点、模型边界和统一重置。定时回调和异步等待归属于当前实例，切换章节/实验或重置会取消；异步操作禁止重复启动。
- 内存二次扫描过滤上次候选集。唯一候选仅是待验证线索，写入错误字段不会假装改变金币。修正覆盖层截图、检测与处罚的绝对化说法。
- 新增 MIDlet 生命周期、RecordStore 模拟，共 6 个课程窗口。RecordStore 实际计算 Java writeInt 的大端四字节；原例覆盖记录，不自动取最高分。

## 验证

- `node scripts/verify_browser_labs.js`：4,384 组排序结果、输入不变性、最终元素身份、冒泡/插入稳定性、移动计数；字节码 int 边界与分支；四种文件头、截断与偏移越界；64 种协议分段、中文、空消息、残帧、非法 UTF-8、超长；XOR 恢复；18 章和 28 演示注册及代码覆盖清单。
- `node scripts/verify_simulations.js`：6 个课程适配器，计算器、小球、方块和 RecordStore 字节编码。
- `python scripts/verify_runner.py`：3 项静态服务测试：无执行 API、页面/Worker 与 WASM 缓存类型；真实执行在浏览器检查。
- `node scripts/verify_line_explanations.js`：签名构造、字符串关键字、Java 控制流/模板、注释、SQL 等语义回归；11,553 行源码无空解释或异常，18 个实验指定的小节均存在。全量遍历不等于每行释义都已人工审校。
- `node scripts/verify_content.js`：50 个页面脚本、131 章、131 练习及图解/演示引用通过。
- 浏览器检查全部 28 个知识演示挂载、关键操作、重置；18 个逆向入口挂载，逐步模型单步操作；四种排序到终点、回退与重置；哈希、内存扫描、协议错误、签名故障及插桩结果差异。
- 131 章在 320、390、768、1440px 宽度检查代码头和新实验容器，共 **524 项**；46 个实验入口在相同四个宽度检查，共 **184 项**。未发现所检查容器横向越出视口。131 章浏览器实际围栏块数量合计 1,044，与清单一致。
