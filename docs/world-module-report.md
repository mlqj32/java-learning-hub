## 运行与交互

- 15 个模型均为独立、确定性的 JavaScript 函数，正文代码直接由函数生成；第一章包含启动与恒温箱两个实验。
- 图形实验与正文 Worker 使用同一算法。无本机编译器、设备、无线通信或执行 API。
- 每个实验均可调参数、重算、前进、后退、播放、暂停、复位和定位进度；172 个语义检查点映射到实际函数源码。
- 回放是有意义的计算检查点，不冒充逐机器指令调试器。任意编辑规则在正文 Worker 运行，图形参数实验保持课程原算法。
- 当前状态与解释原位呈现；参数修改后暂停并锁定旧回放，重算才更新；非法参数保留上次有效结果并明确提示。
- 年份与类型范围使用专用图解；其他实验使用量纲明确的曲线/阶段图，另有起搏事件、数据位和字节指令显示。
- 手机上图形独立横向滚动，最小图形字号约 15.6px，页面不被撑宽；控制按钮最小高度 44px。

## 事实与模型边界

“一个回车控制起搏器”的特定说法未找到足以确认出处的一手资料，正文以提交命令的比喻解释，不虚构已证实的攻击致死事件。CISA 的近距离无线条件、特定型号与缓解背景单独说明。

所有医疗和航天模型均为教学简化，不是临床、飞控、真实轨道或辐射可靠性仿真。阿丽亚娜的教学向零截断不冒充 Ada 原转换舍入；普通 Hamming 不声称 SECDED；凌日与频谱不把候选当作生命发现；灭绝后的结论明确区分事实、条件推理和未知。
