# 设计模式 UML 补齐

完成日期：2026-11-15。

原先用 TEXT 代码块绘制的模式结构已替换为本地 SVG UML。新增 26 张图：23 种 GoF 模式、简单工厂、类图入门、六种关系速查。每张模式图放在相应正文段落，附具体职责、字段/方法、读图顺序及该图实际使用的关系图例。

| 章节 | 图示覆盖 |
| --- | --- |
| pat2 · UML 与设计原则 | 类图入门、六种关系 |
| pat3 · 创建型 | 单例、简单工厂、工厂方法、抽象工厂、建造者、原型 |
| pat4 · 结构型 | 代理、装饰器、适配器、外观、桥接、组合、享元 |

类图按角色、类名、字段、方法分区，使用实线/虚线与空心三角、开放箭头、菱形表达真实关系。接口实现与类继承分开绘制；聚合/组合说明依据所有权和生命周期，修正“仅凭注入或 new 判断”的旧说明。图中省略无关成员；概念角色与可选角色明确标注。

使用现有独立图解查看器：可打开、放大、缩小、适应窗口和关闭。小屏在图解区域内横向浏览，不压缩整个页面。默认放大窗口保留较大的图宽，用户可主动选择“适应窗口”查看全貌。

## 验证

- 对 320、390、768、1440、1920 五种宽度逐章测量，共 25 个页面状态、130 次图解检查。未发现文字越过类框、关系标签遮挡类框、连线穿过无关类框或页面横向溢出；所有类图文字均完整显示，无省略。
- 在 1440 宽度逐一打开并关闭 26 个图解窗口，均正常，没有按钮越出窗口。另在 390 宽度验证放大和适应窗口。
- 自动检查通过：`verify_pattern_uml.js`、`verify_content.js`、`verify_pattern_examples.js`、`verify_line_explanations.js`。覆盖全部模式的实际章节引用、箭头端点、唯一 SVG 标识、标记引用与已有 Java 示例入口。
- 字体子集重新生成，相关静态资源缓存版本已更新。SVG 渲染无需外部图表服务。
