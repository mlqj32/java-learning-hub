# 大屏阅读布局 · 2026-11-15

原布局限制整体宽度为 1536px、正文为 850px，大屏下形成过多外侧留白。本次将整体上限扩大为 2400px，常规内容区扩大为 1280px，并使顶部导航与整体布局对齐。

章节在 1500px 及以上使用「章节侧栏 / 正文 / 本章导航」布局：右侧导航固定在可视区内，过长时可独立滚动；点击小节只滚动正文，不改变课程路由。正文、代码和图表共享扩展后的中间列，独立文字段落保留 1120px 的宽度上限。

小于 1500px 时，本章导航回到正文顶部的折叠目录；900px 及以下保留可展开的章节侧栏。专注阅读模式隐藏两侧导航，正文上限保持 850px。

- 已点击右侧目录并核对课程路由保持不变；已验证专注阅读切换及宽屏恢复。
