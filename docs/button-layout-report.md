## 浏览器检查

使用网页 UI 切换实验、打开章节、展开实验和图形窗口，通过只读 DOM 几何数据检查按钮间距、文字溢出、按钮越界与页面水平溢出。

| 范围 | 屏宽 | 检查结果 |
| --- | --- | --- |
| 全部 28 个知识演示、18 个逆向实验入口 | 1440 / 768 / 390 / 320px | 184 组通过 |
| 全部 131 个章节，展开章节实验 | 1440 / 768 / 390 / 320px | 524 组通过 |
| 首页、路线、题库、图解总览及 17 个模块页 | 1440 / 768 / 390 / 320px | 84 组通过 |
| 五种语言的运行面板 | 1440 / 768 / 390 / 320px | 20 组通过 |
| 六种图形窗口，按所属的两个章节展开 | 1440 / 768 / 390 / 320px | 8 组通过 |
| MVCC 生成快照后的卡片与 ReadView | 1440 / 768 / 390 / 320px | 4 组通过 |

合计 824 组布局状态。相邻按钮的检测阈值为 7px，实际共用操作区间距为 12px、计算器为 10px。检查覆盖页面已显示的按钮；阅读器和运行面板的展开状态另外抽查，不代表穷举每个示例的每种运行状态。

操作复核：MVCC 首次读取 500 → B 提交 → RR 仍为 500 → RC 为 400；重新开始正常。320px 下展开/关闭逐行阅读正常；计算器按 `7 + 8 =` 显示 `15.0`。

维护校验：`node scripts/verify_content.js`、`node scripts/verify_simulations.js` 通过。网站运行方式仍为浏览器虚拟环境。

逐页数据见 [button-layout-validation.json](button-layout-validation.json)。目录、桌面章节及运行面板的早期完整扫描以汇总保存，其余扫描保留逐页数据。
